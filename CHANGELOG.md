# Changelog

## 1.0.0 — 2026-10-01

### English

Initial stable release of **Codex Status Icons**, its VS Code extension and SSH component.

- Independent status icon for each local or SSH VS Code window.
- Four states, working duration, automatic account quota detection and remaining quota in tooltips.
- Native Windows notifications for task completion and quota interruptions.
- ChatGPT, Windows, silent and custom WAV notification sounds.
- Three icon styles and sizes, custom project letter and stable Windows icon identities.
- French and English interface, three-tab settings panel, Help / About and technical diagnostics.
- Automatic SSH component installation and background-response handling for minimized windows.
- Bilingual installation guides and source-build documentation.

### Français

Première version stable de **Codex Status Icons**, de son extension VS Code et de son composant SSH.

- Icône indépendante par fenêtre VS Code locale ou SSH.
- Quatre états, durée de travail, détection automatique des limites et quota restant dans les infobulles.
- Notifications Windows natives pour les fins de tâche et les interruptions liées au quota.
- Sons ChatGPT, Windows, silencieux et WAV personnalisé.
- Trois styles et tailles d'icônes, lettre personnalisée et identités Windows stables.
- Interface française et anglaise, paramètres en trois onglets, aide et diagnostics techniques.
- Installation automatique du composant SSH et gestion des réponses en arrière-plan des fenêtres minimisées.
- Guides d'installation bilingues et documentation de compilation.
